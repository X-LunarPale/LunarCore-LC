# 社区模块 / Community Modules

[投稿说明 / Submit a module](../../CONTRIBUTING.md) | [English](../../CONTRIBUTING.en.md) | [市场 / Market](../README.md)

所有人均可通过 PR 添加模块条目，也可通过 Issues 投稿。每个 `模块ID.json` 是一个可查看名称、用途和公开下载链接的市场条目。

Everyone can add a module entry through a PR or submit it through Issues. Each `module-id.json` contains its names, purpose and public download link.

目前尚无社区投稿。`../submission.example.json` 为填写示例，不是可下载模块。

No community modules have been submitted yet. `../submission.example.json` is a template, not a downloadable module.
