适用于 **v0.0.6 测试预览版**，需要 Java 25、Paper 26.3 build 202。核心只带基础命令，以下模块按需安装。

## 安装方式

推荐使用面板“模块管理 → 模块市场”。手动安装时，停服后将模块 JAR 放入 `plugins/LunarCore/modules/`，再启动服务器。不要直接放入 `plugins/`。

更新时替换旧文件，不保留重复 JAR。卸载只删除 JAR，配置和数据可以保留。依赖模块必须一起安装。

## 发布与收录

所有人都可以上传自己的模块：在自己的公开 Release 上传 JAR，然后通过 PR 将模块条目加入 `community/`，也可使用 Issues 投稿表单。填写用途、适用版本、依赖、许可、源码和下载链接，系统会自动检查格式。

上方 19 个官方模块支持面板一键安装，社区模块下载后手动安装。投稿目录通过 PR 合入，不需要仓库访问令牌。本项目代码使用 GPL v3，第三方许可保留。
