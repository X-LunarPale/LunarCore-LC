# v0.0.9 预发行（0.0.9-pre.1）

[English](../en-US/RELEASE.md) | [首页](../../README.md)

## 本版变化

- WebUI 操作期间暂停相关刷新并禁止重复提交。模块列表读取失败可重试，更新失败保留旧列表；操作成功后的菜单更新失败会单独提示。
- 减少隐藏页面和未打开模块的定时请求，搜索输入需提交后才影响表格查询，避免刷新打断编辑。
- 自动公告的开关、间隔与内容保存后立即应用。重载、禁用时释放旧公告与显示任务，避免重复执行。
- 聊天、TAB 玩家名称和头顶称号可分别设置，并提供世界名称、颜色和称号预览。世界方括号可跟随世界颜色；头顶称号可设置高度与可见距离。
- 兼容旧自定义聊天格式和显示开关，只更新旧内置模板。内置管理格式移除管理标签，保留蓝色玩家名。
- 优化模块状态与玩家提示，区分未启用、没有变化、正在处理和实际失败，减少含糊的成功或错误信息。
- 修复 QQAuth 在离线服身份变化后的账号恢复流程。

## 升级

停服后替换核心和需要更新的同版本模块，保留原有配置、数据库与世界。完整启动后，在“模块管理”检查状态。

聊天设置现分为过滤、公告、聊天外观、头顶称号和玩家列表。旧自定义格式继续保留；新建配置默认不在聊天和 TAB 玩家名前显示称号，头顶显示单独开启。若 PlayerTitle 与 LC 重复显示，请关闭其中一方对应的显示功能。详见[使用说明](USAGE.md#聊天显示与公告)。

地形仍需在 Java 命令的 `-jar` 前添加 `-javaagent:LC-Terrain-Agent.jar`。更新启动补丁后需完整重启。
