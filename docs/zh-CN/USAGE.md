# 面板与常用功能

[English](../en-US/USAGE.md) | [首页](../../README.md)

LunarCore 简称 LC。游戏内输入 `/lc help` 查看管理命令，管理员可用 `/lc m list` 快速查看模块状态。普通基础命令仍可直接输入。自定义文本中的变量使用 `%lc_模块_变量%`，例如 `%lc_core_online%`。

## 账号与登录

在“账号与角色”分配面板权限。观察者查看基础状态，协管管理已授权功能。游戏权限由官方 LuckPerms 管理，与面板账号分开。LC 的“权限管理”直接连接 LP，安装和常用操作见[权限设置](PERMISSIONS.md)。

忘记面板密码时，在服务端控制台执行 `lc web user passwd 账号 新密码`。不要公开包含密码的记录。若 admin 同时丢失验证器与恢复码，可执行 `lc web resetadmin`，它会重置 admin 密码并清除该账号的两步验证。

## 两步验证

在“个人设置”输入当前密码，选择设置两步验证。用验证器扫描二维码，输入动态验证码并确认。以后登录需再输入验证码。

保存一次性恢复码，以便丢失验证器时登录。普通改密不会关闭两步验证。升级时保留数据库与 `web.jwt-secret`，否则已绑定的验证器可能需要重新设置。

## 名称、Logo 与语言

在“服务器配置 → 品牌设置”分别保存或恢复名称、Logo。Logo 支持 PNG/JPEG，最大 256 KiB，宽高不超过 1024 像素。名称和 Logo 会公开显示在登录页。

登录页和面板顶部可切换中英文。玩家输入、配置内容和控制台日志保留原文。

## 维护与定时

在“服务器展示与维护”选择手动或定时控制。手动模式由维护开关控制；定时模式设置一次维护的开始和结束时间，结束后自动开放。结束时间可留空，需要提前结束时切回手动并关闭维护。

日期和时间按当前设备的时区显示。服务端重启后会恢复计划状态，不会重新踢人。开启自动踢出时，只在进入维护或维护中开启该选项时执行一次，白名单玩家除外。

维护控制、白名单、提示消息和服务器简介分别编辑、分别保存。自动刷新只更新运行状态，保留草稿。手动踢出使用已保存的白名单和提示。

## 聊天显示与公告

在聊天设置中为世界填写显示名称和颜色，英文世界目录保持不变。开启“世界名称自带同色方括号”后，`{world}` 已含方括号，格式里无需再写一层。

聊天、TAB 玩家名称和头顶称号分别控制。新建配置默认不在聊天和 TAB 玩家名前显示称号；头顶称号可独立启用，并设置高度和可见距离。内置管理格式保留蓝色玩家名，不再额外显示管理标签。

显示预览可选择示例世界、玩家、称号和消息，不会发送到游戏。预览仅供参考，以客户端实际显示为准。原有自定义格式继续保留；升级不会统一覆盖已设置的格式和称号开关。

自动公告的开关、间隔和内容保存后立即应用。重载或禁用聊天模块时会停止旧公告任务，避免重复发送。

## 游戏内 AI

先安装聊天模块，再进入 AI 聊天设置：

1. 填写模型服务地址（Base URL）、API Key 和模型名称。
2. 设置 AI 名称、人格与聊天格式，保存。
3. 选择被提及时回复，或允许按设定概率主动回复。
4. 按需添加其他 AI 角色、备用模型与记忆。

主模型请求失败时会尝试备用模型。嵌入模型会把文字转换成便于查找的数字，用来寻找相关旧对话，需要另行配置。

可以获取服务商模型列表，查询 DeepSeek 与支持的 sub2API 余额。是否可用取决于上游接口；自动查询会定期读取余额。

出错时可回复自定义消息，也可保持沉默。外部 AI 调用可能收费，相关聊天内容会发送给所选服务商。

## QQ 认证与提示预览

可修改群号、连接方式、绑定限制和提示消息。预览只显示示例，不向 QQ 或玩家发送消息。

默认要求先完成 QQ 验证。关闭“强制 QQ 验证”后，玩家可直接注册和登录游戏；未绑定玩家每天登录后提醒一次，可用 `/qqauth bind` 获取验证码，再到指定 QQ 群发送 `/验证 验证码`。

未完成 QQ 验证不能自助改密、恢复密码、注销或解绑。每日提醒可关闭，日期按设置的时区计算；留空使用服务器时区，重连与重载不会重复提醒。

提示消息保存后立即生效；其他设置需点击“应用配置”、执行 `qqauth reload` 或完整重启。重载会撤销在线认证并断开玩家连接。启用步骤见[模块使用](MODULES.md)。

## GrimAC、性能与世界

反作弊模块提供 GrimAC 中文配置名。保存后需主动重载 GrimAC；不支持的项目保持只读。

性能优化默认关闭，应先了解用途再启用；操作数不代表性能提升。地形模块只生成独立新世界，不转换旧世界。安装或调整支持高度后需完整重启。世界卸载会保存并停止加载，不删除目录。

在“世界管理 → 配置”中，可为每个世界分别允许或禁止前往主世界、下界和末地。例如只关闭“允许前往下界”，仍可正常前往末地。传送门和跨维度传送均遵守设置，同一环境传送不受影响，保存后立即生效。

地形模块还需在启动命令加入 `-javaagent:LC-Terrain-Agent.jar`，用于气候、神殿位置和旧区块衔接。安装方式、全部设置与 `/tectonic` 命令见[地形说明](../../modules/lc-terrain/README.md)。

## NPC 随机传送

NPC 以控制台身份执行 `rtpnpc 世界 玩家名 [半径]`，将玩家传送到目标世界 `(0,0)` 周围的安全位置。默认圆形半径 1000 格；世界须已加载。NpcPlugin-Paper 的点击命令可填 `rtpnpc world @s 1000`，执行者选 `CONSOLE`，其中 `@s` 代表点击玩家。

该命令无需预热、不收费，保留随机传送冷却、领地检查和 `/back` 记录。普通玩家无需获得 `lc.teleport.rtp.npc` 权限。
