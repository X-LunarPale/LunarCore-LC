# 面板与常用功能

[English](../en-US/USAGE.md) | [首页](../../README.md)

LunarCore 简称 LC。游戏内输入 `/lc help` 查看管理命令；普通基础命令仍可直接输入。自定义文本中的变量使用 `%lc_模块_变量%`，例如 `%lc_core_online%`。

## 账号与登录

在“账号与角色”分配面板权限。观察者查看基础状态，协管管理已授权功能。游戏权限由权限模块或其他权限插件管理，与面板账号分开。

忘记面板密码时，在服务端控制台执行 `lc web user passwd 账号 新密码`。不要公开包含密码的记录。若 admin 同时丢失验证器与恢复码，可执行 `lc web resetadmin`，它会重置 admin 密码并清除该账号的两步验证。

## 两步验证

在“个人设置”输入当前密码，选择设置两步验证。用验证器扫描二维码，输入动态验证码并确认。以后登录需再输入验证码。

保存一次性恢复码，以便丢失验证器时登录。普通改密不会关闭两步验证。升级时保留数据库与 `web.jwt-secret`，否则已绑定的验证器可能需要重新设置。

## 名称、Logo 与语言

在“服务器配置 → 品牌设置”分别保存或恢复名称、Logo。Logo 支持 PNG/JPEG，最大 256 KiB，宽高不超过 1024 像素。名称和 Logo 会公开显示在登录页。

登录页和面板顶部可切换中英文。玩家输入、配置内容和控制台日志保留原文。

## 游戏内 AI

先安装聊天模块，再进入 AI 聊天设置：

1. 填写模型服务地址（Base URL）、API Key 和模型名称。
2. 设置 AI 名称、人格与聊天格式，保存。
3. 选择被提及时回复，或允许按设定概率主动回复。
4. 按需添加其他 AI 角色、备用模型与记忆。

主模型请求失败时会尝试备用模型。嵌入模型会把文字转换成便于查找的数字，用来寻找相关旧对话，需要另行配置。

可以获取服务商模型列表，查询 DeepSeek 与支持的 sub2API 余额。是否可用取决于上游接口；自动查询会定期读取余额。

出错时可回复自定义消息，也可保持沉默。外部 AI 调用可能收费，相关聊天内容会发送给所选服务商。

## QQ 认证与提示预览

可修改群号、连接方式、绑定限制和提示消息。预览只显示示例，不向 QQ 或玩家发送消息。

保存后需重载 QQ 认证或完整重启才生效。重载会撤销在线认证并断开玩家连接。启用步骤见[模块使用](MODULES.md)。

## GrimAC、性能与世界

反作弊模块提供 GrimAC 中文配置名。保存后需主动重载 GrimAC；不支持的项目保持只读。

性能优化默认关闭，应先了解用途再启用；操作数不代表性能提升。地形模块只生成独立新世界，不转换旧世界。安装或调整支持高度后需完整重启。世界卸载会保存并停止加载，不删除目录。

地形模块还需在启动命令加入 `-javaagent:LC-Terrain-Agent.jar`，用于气候、神殿位置和旧区块衔接。安装方式、全部设置与 `/tectonic` 命令见[地形说明](../../modules/lbr-terrain/README.md)。
