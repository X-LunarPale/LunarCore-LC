# 探索手册

`lc-journal` 为原版生存提供个人收藏记录，不修改世界生成、掉落或战斗，也不发放奖励。

- `/journal`：分页查看生物群系、原版进度和钓获物品种类。
- `/journal stats`：查看个人记录数量。
- Bukkit 权限 `lc.journal.use` 默认授予普通玩家。

仅在配置的世界白名单中记录生存或冒险模式玩家的活动。生物群系按低频位置采样，原版进度只接收启用后完成的非配方 `minecraft` 进度，钓获仅接收未取消的成功钓鱼事件中的物品种类。不扫描或补填安装前的历史；“首次记录”指本模块首次实际观察到的时间。采样期间快速穿过的生物群系可能不被记录。钓获按物品类型去重，不按附魔、耐久或自定义名称细分。

`config.yml` 支持总开关、世界白名单、2–60 秒的生物群系采样间隔、三个收藏分类开关及默认关闭的私聊通知。空白名单表示所有世界均暂停新增记录。暂停记录和更改配置保留历史数据。游戏消息提供 `zh_CN`、`en_US` 语言包，原版收藏名称在库存界面使用客户端翻译；首次记录时间采用服务端时区。

共享数据库中的 `journal_entries` 表使用玩家 UUID、分类和条目标识的联合主键；重复发现或重启后的重放不会覆盖原时间、世界或玩家名字。运行中的 SQL 在独立、有限队列的 IO 线程执行。写入失败保留原始待写条目，每 5 秒重试。待写队列上限为 10,000 项，满时暂停接受新种类并记录警告，不驱逐已有待写记录。

写入批次前后会原子保存模块目录的 `pending.dat` 快照。正常停用先停止采集、保存快照，再最多等待 5 秒完成 IO；超时或数据库故障会在下一次启用时幂等重放未确认记录。数据库语句设有 3 秒超时；连接池与驱动仍须支持中断/超时才能及时结束正在进行的单次数据库调用。进程突然退出时，自上次快照后最多约 5 秒内的新事件可能尚未保存。快照损坏会阻止本模块启用并保留原文件，避免静默覆盖。

库存 GUI 使用自定义 holder，取消顶层与底部库存的所有点击、shift、双击、数字键交换及拖动。分类请求合并至最新选择，旧分页响应不能覆盖当前页；重复 `/journal` 复用已打开界面。菜单中的世界名、标识等动态文本作为安全的消息参数构造，不作为 MiniMessage 模板解析。

## Web 面板

面板 ID/命名空间为 `journal`，查看权限 `journal.view`，保存权限 `journal.manage`。面板提供统计、可搜索分页记录和配置表单；没有删除、重置或奖励功能。

- `GET /api/ext/journal/stats`：声明式统计数组。
- `GET /api/ext/journal/records?page=1&size=20&q=...&category=biomes`：`{total,items}`；分类可省略，也可为 `advancements`、`fishing`。
- 每条记录含 `id,uuid,player,category,key,label,world,first_seen`，时间为毫秒时间戳。
- `page` 为 1–1,000,000 的整数，`size` 为 1–100 的整数，搜索最多 100 字符；非法参数返回 400，数据表尚未准备好返回 503。
- `GET /api/ext/journal/config`：`enabled,worlds,sample_seconds,record_biomes,record_advancements,record_fishing,notify_discoveries`。`worlds` 为每行一个世界名的文本。
- `POST /api/ext/journal/config`：接受上述字段的完整或局部 JSON 对象；布尔值严格检查，未知字段拒绝。验证后原子保存，再发布不可变配置快照，失败保留旧配置。成功保存写审计日志。

`journal.view` 可以读取范围配置；仅有 `journal.manage` 的用户仍需查看权限才能看到面板。观察者应保持无上述权限，协管可通过现有通配权限使用。

## 验证

定向测试覆盖真实 SQLite 去重与重启时间保持、分类/玩家隔离、搜索及分页、失败保留与重试、队列边界、快照恢复和损坏保护、配置校验及进度过滤。真实客户端的钓鱼/进度事件、库存交互与服务端关闭时的驱动超时行为仍需现场验收。
