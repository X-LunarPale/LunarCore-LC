# lc-performance

GPL-3.0-only LC 性能模块，包含原创监控/有界掉落物清理及基于 lychee 的 LagFixer build-151 的源码移植。入口 `com.lunarboreal.performance.PerformanceModule`，模块 ID `performance`。

内置十三个独立开关：低TPS保护、红石、爆炸、加速树叶衰减、漏斗、实体限额、世界清理/有限Abyss、垃圾箱、玩家能力、AFK、真正NMS生物Goal适配、有限原版载具替换及插件日志过滤。全部默认关闭。上游实际注册十二项；漏斗由本项目补接为事件节流。移植进行了生命周期、主线程、预算和保护方面的修改，不代表与上游所有行为相同。

Web 面板的“功能开关”直接提供中文布尔开关，点击“应用功能开关”一次保存全部修改，不逐项弹出确认框。新开启子功能会自动开启所属模块及必要父功能；单独关闭模块时，未改变的子开关不会阻止关闭。加载面板不会修改配置，也不会自动全部启用。

“全部启用／全部关闭”立即保存并应用十三个内置模块及已列出的子功能开关，包括低 TPS 负载保护各暂停项、动态视距、爆炸限制、漏斗节流、实体超限清理各类型、世界清理各类型与回收箱、垃圾箱定时清理与禁止直接丢弃、挂机处理、生物繁殖/诱食、船只及矿车优化。只保存一次、只重载一次，不要求逐项操作。世界列表、数值限额、实体名单、日志过滤规则及宠物保护等策略值保持不变；规则或名单为空仍可正常应用，不另设启用前置。外部 LagFixer 桥接、LC 独立掉落物清理不在一键范围内。关闭会执行现有生命周期恢复；垃圾箱和回收箱关闭时退还尚存物品，已经删除的物品不能恢复。写盘失败撤回本次全部内存修改。

无需安装独立LagFixer。外部固定monitor命令桥接仍是另一个默认关闭的功能；外部上游build-151自身的Paper26.3兼容性未验证。不要同时启用两套相似优化后推定行为一致。

完整来源、配置、Web权限与行为差异见 [性能说明](../../docs/PERFORMANCE.md) 和 [第三方声明](../../THIRD-PARTY-NOTICES.md)。原始源码及许可位于 `third-party/lagfixer/upstream`。

常规构建使用固定Paper26.3 build202开发包。若构建主机Codebook ZIPFS异常，可先在独立目录启动同版本Paper，让其提取server与libraries，再使用 `./gw.sh :lc-performance:test -Plc.paperServerHome=<相对此模块或绝对服务端路径>`；该目录仅编译依赖，不会打入分发包。示例本地验证目录参数为 `../../run-alpha2`。所有运行功能必须再经隔离服和客户端复测；单测不代替真实Minecraft行为。
