# lbr-vote 全服玩法投票

灵感来自Minecraft April Fools的支持/不支持玩法，独立模块，不执行玩家输入命令，不修改其他模块的数据。核心现有模块收集会自动打包此模块。

## 明确规格

- `/vote`（别名`/lbrvote`）需`lbr.vote.use`，默认所有玩家；发起另需`lbr.vote.start`默认OP，取消/停止需`lbr.vote.admin`默认OP。Web为独立`vote.view`/`vote.manage`权限，不等于游戏权限，Web不能代投。
- 启动时固定名单：配置世界中在线、生存/冒险、有use权限的UUID；默认至少3人，硬上限200。创造/旁观不投、不受影响。后来上线玩家不能加入该轮选民，但在效果期间进入合格世界/模式可收到同样效果。离线票仍算，重连不可再投。
- 每UUID一票，支持或不支持，不允许改票；发起人不自动支持。截止前最后一秒也必须写盘成功才计票。
- 默认参与人数至少ceil(选民数×0.5)；支持票至少ceil(有效票×0.6)，且支持严格大于不支持。无票、未达门槛、平票均失败。门槛与比例取启动时快照，不能通过中途改配置影响结算。
- 投票默认60秒、硬限30..300秒；效果默认60秒、硬限15..300秒，可用max-*进一步收紧。墙钟截止，主线程每秒检查，低TPS可能延迟结算；不会按错过的周期补发效果。
- 全服最多一个投票或一个进行中效果，互斥不排队；全局发起冷却默认300秒、硬限60..86400，从成功发起计时，取消不退冷却。无任意标题/命令/效果ID输入。
- 可周期发起随机提案：automatic默认关闭，间隔900秒、硬限300..86400；仅白名单pool和已启用效果；仍需在线门槛及玩家实际投票，通过后才有效果。

## 预定义效果及公平边界

| ID | 收益 | 代价（同时施加） | 默认 |
|---|---|---|---|
| speed | 速度I，赶路更快 | 饥饿I，饱食度消耗更快 | 开 |
| jump | 跳跃提升I，跳得更高 | 虚弱I，近战伤害降低 | 开 |
| slow | 急迫I，挖掘更快 | 缓慢I，走得更慢 | 关，可选完整组合，保留旧ID |

每项提案本身同时有好处与坏处，不存在单独的纯收益或纯惩罚提案。命令status、发起/结算广播、Web当前状态与提案表均明确列出收益和代价。效果类型/等级不可配置，仅允许启用固定白名单组合；不能配置任意命令或移除代价。

仅一级、有限时长且不直接扣血的效果。饥饿会真实消耗饱食度，效果停止不返还已经消耗的食物；困难难度下后续饥饿和战斗弱化可能间接增加死亡风险，应备好食物并优先限制娱乐世界。反对、弃权、支持者同条件，管理员不能选受益者。不发物品/金钱、不传送、不破坏世界、不改gamerule，不存在任意控制台命令执行。worlds可限制专用娱乐世界；enabled=false可关闭玩法。速度/跳跃仍会影响PVP/跑酷，正式玩法世界需服主决定。

每秒续租60tick短药水，尊重已有同类药水，不先移除原药水。组合中任一类型已由外部来源占用时整组跳过，清除自己的另一半；先施加代价，再施加收益，任一添加被保护插件拒绝则撤回自己已加的部分。外部修改后至下一次检查最长约1秒可能只剩半组；清理被其他插件取消时最多剩60个在线tick，不以强制覆盖消除这种边界。模块跟踪自己添加的效果，只清除仍符合自身指纹的效果；外部插件药水事件会使模块放弃归属。效果到期、管理员stop/cancel、退出、模式/世界不匹配、重载和停用会清理；退出监听先移除防离线冻结。不强行覆盖/删除别的插件效果；其他插件取消清理事件时，自己的短租最多还有60个在线tick。崩溃恢复不重放效果，残留短租自然到期；不声称崩溃时瞬间撤销。相同类型/属性且不发事件的直接NMS修改无法可靠识别归属。

## 命令

```
/vote status
/vote yes
/vote no
/vote start speed 60 90
/vote start jump
/vote start slow 120 30
/vote cancel
/vote stop
```

start的两个可选参数依次为投票和效果秒数；不给则用配置。cancel和stop均撤销当前投票及效果，保留历史/冷却。没有OP绕过门槛/强制通过/代投。

## 持久化及失败

`plugins/LunarCore/modules/vote/state.properties`原子临时文件替换，保存固定选民、每人票、门槛、截止、效果标记、冷却和最近50事件。每次投票同步写盘完成后才公布，最多200票；不会将投票写入其他模块数据库。写盘失败停止效果、拒绝后续操作并记录严重日志，修复存储后重载。文件损坏/未知格式拒绝启用，不默默覆盖。依赖同目录原子rename支持，不降级为不安全覆盖；小服写盘频率为每票一次，需观察磁盘延迟。

正常重载/停用/启动均取消未完成投票和效果，保留审计历史及冷却；不会趁玩家离线结算执行。效果落盘标记在施加前保存，重启识别为取消。首次启用没有投票、周期提案默认关闭。

## Web

命名空间`/api/ext/vote`，声明式面板“全服玩法投票”自动由现有UI渲染，不新增前端框架。

| 方法/路径 | 权限 | 内容 |
|---|---|---|
| GET /status | vote.view | 当前投票/效果、healthy、人数及截止 |
| GET /current | vote.view | status分页包装用于面板 |
| GET /effects | vote.view | 固定效果白名单、利弊、配置开关分页 |
| GET /history | vote.view | 最近50条事件分页 |
| POST /start | vote.manage | JSON effect、voteSeconds、effectSeconds；严格字段和整数范围 |
| POST /stop | vote.manage | 空body或{}；取消投票并停止效果 |

命令/Web/周期结算全部在Bukkit主线程串行更新；Web读不可变状态，Bukkit读写经sync。Web发起和停止写LBR审计。详细参数修改模块config再通过现有模块重载；不提供全配置任意写接口。

## 验证

`./gw.sh :lbr-vote:test :lbr-vote:jar`：10项JUnit，新增覆盖三个固定收益/代价组合、任一外部效果阻止整组和自有组合续租；原测试覆盖不可变名单/每人一票/外部UUID、参与门槛/比例/平票、截止、NaN/非法快照、全字段持久化、损坏拒绝和写入失败保留旧文件。

人工/隔离服仍须验证：3个真实玩家yes/no、未达门槛、重连重复、后来加入拒绝；完整30秒截止及15秒效果；已有同类药水/外部插件覆盖不受损；世界和游戏模式切换、退出后重新加入；stop/reload/disable/重启清理；Web权限/严格参数；磁盘故障日志；自动提案冷却；PVP及反作弊配合。单测不代表以上客户端玩法已经通过，不承诺Folia兼容。
