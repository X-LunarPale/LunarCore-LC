# 地形命令

`/tectonic` 需要 `lc.terrain.command` 权限，默认仅 OP 可用。
查询对象必须是已经加载的 LunarCore 地形世界。

| 命令 | 作用 |
| --- | --- |
| `/tectonic debug [世界]` | 查看当前位置的地形区域、侵蚀值、区域选择值和洞穴截断值 |
| `/tectonic locate <地形> [世界]` | 查找附近符合条件的地形 |

玩家省略世界名时使用当前世界。控制台须填写已加载的地形世界名，
或 `lc_terrain:alpine` 这样的世界标识。
指定其他世界时，从该世界的出生点开始查找。

| 地形名称 | 中文 |
| --- | --- |
| `mountain_range` | 山脉 |
| `underground_river` | 地下河 |
| `jungle_pillars` | 丛林石柱 |
| `rolling_hills` | 起伏丘陵 |
| `badlands_canyon` | 恶地峡谷 |
| `badlands_plateaus` | 恶地高原 |
| `desert_dunes` | 沙漠沙丘 |
| `cherry_valley` | 樱花山谷 |

查找条件与官方 Tectonic 3.0.29 保持一致：数值先取三位小数，再判断是否
落入范围；每隔 64 格采样，按半径 400 个采样点的方形螺旋向外查找。
查询在后台进行，不会因此加载或生成区块。该世界未启用的地形不可查找。

结果表示地形形态的位置，该位置的生物群系名称可能不同。点击坐标只会
填入传送命令，不会自动传送玩家。

旧地形区块没有当前生成标记时，会保留原有高度范围，交给原生区块混合
功能处理，并在加载时重算高度图和光照。该兼容逻辑仅作用于 LunarCore
地形世界，不修改原主世界。
